# 📐 Diagramas del Proyecto Smart Math

## Descripción

Esta carpeta contiene los diagramas técnicos utilizados para representar la estructura, funcionamiento y arquitectura del sistema inteligente **Smart Math**.

Los diagramas permiten comprender la interacción entre los componentes de hardware y software, así como el flujo de información dentro del prototipo.

---

# Contenido

Dentro de esta carpeta se encuentran los siguientes diagramas:

## 📊 01_Diagrama_de_Bloques

Representa la estructura general del sistema y la comunicación entre los principales módulos.

Incluye:

- ESP32
- Pantalla OLED
- Sistema de audio
- Usuario
- Algoritmo principal

---

## 🔄 02_Diagrama_de_Flujo

Describe la lógica de funcionamiento del sistema desde el inicio hasta la generación de nuevas preguntas matemáticas.

Incluye:

- Inicialización.
- Generación de preguntas.
- Temporizador.
- Validación.
- Retroalimentación.

---

## 👤 03_Diagrama_Caso_de_Uso

Representa la interacción del usuario con el sistema Smart Math.

Incluye las acciones principales del estudiante durante una sesión.

---

## 🔌 04_Arquitectura_Hardware

Muestra la distribución física de los componentes electrónicos utilizados.

Incluye:

- ESP32.
- OLED.
- INMP441.
- MAX98357.
- Bocina.
- Protoboard.

---

## 💻 05_Arquitectura_Software

Representa la organización lógica del programa y sus módulos principales.

---

## ⚡ 06_Diagrama_Electrico

Muestra las conexiones realizadas entre el microcontrolador y los dispositivos electrónicos.

---

## 🧩 07_Diagrama_de_Componentes

Describe los elementos principales que conforman el sistema y su relación.

---

# Objetivo

Documentar visualmente el diseño del sistema para facilitar su comprensión, mantenimiento y futuras mejoras.
