# 01_Documentacion

## Proyecto Smart Math

Esta carpeta contiene la documentación oficial del proyecto **Smart Math**, desarrollado para la asignatura **Sistemas Inteligentes**.

El objetivo de esta documentación es presentar de manera organizada la información técnica, administrativa y funcional del sistema desarrollado utilizando tecnología embebida basada en ESP32.
