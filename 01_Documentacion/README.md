# 📖 Descripción General

**Smart Math** es un sistema inteligente diseñado para fortalecer el aprendizaje de las matemáticas mediante una experiencia interactiva basada en hardware embebido.

El proyecto integra una tarjeta **ESP32 DevKit V1**, una pantalla **OLED de 128x64 píxeles**, un sistema de audio compuesto por un micrófono **INMP441**, un amplificador **MAX98357** y una bocina de **4Ω 3W**, creando una plataforma educativa capaz de presentar ejercicios matemáticos generados aleatoriamente.

Cada operación dispone de un tiempo máximo de **18 segundos**, promoviendo el razonamiento lógico, la concentración y la capacidad de resolver problemas bajo presión de manera controlada.

La propuesta busca demostrar que la tecnología embebida puede convertirse en una herramienta de apoyo para el aprendizaje, complementando los métodos tradicionales de enseñanza mediante una experiencia dinámica, accesible y de bajo costo.

---

# 🎯 Objetivo General

Diseñar e implementar un sistema inteligente basado en tecnología embebida que fortalezca el aprendizaje de las matemáticas mediante actividades interactivas, retroalimentación inmediata y una metodología orientada al desarrollo del pensamiento lógico.

---

# 🎯 Objetivos Específicos

- Diseñar una plataforma educativa basada en un microcontrolador ESP32.
- Implementar un algoritmo capaz de generar operaciones matemáticas de forma aleatoria.
- Integrar una pantalla OLED para mostrar preguntas, resultados e información del sistema.
- Incorporar un sistema de audio que proporcione retroalimentación al usuario.
- Implementar un temporizador de 18 segundos para cada ejercicio.
- Validar el funcionamiento del prototipo mediante pruebas funcionales.
- Demostrar la viabilidad de los sistemas inteligentes como apoyo al aprendizaje.

# 🏗 Arquitectura General

El sistema está compuesto por diversos módulos que trabajan de forma coordinada.

- Unidad de procesamiento (ESP32)
- Módulo de visualización
- Sistema de generación de preguntas
- Temporizador
- Sistema de validación
- Módulo de audio
- Interfaz de usuario

Cada módulo fue desarrollado de forma independiente para facilitar futuras mejoras y mantenimiento.

---

# 🚀 Funcionamiento

El flujo general del sistema es el siguiente:

1. Encendido del dispositivo.
2. Inicialización de los módulos electrónicos.
3. Presentación del menú principal.
4. Generación aleatoria de una operación matemática.
5. Inicio del temporizador de 18 segundos.
6. Captura de la respuesta del usuario.
7. Validación automática.
8. Retroalimentación visual y auditiva.
9. Generación de una nueva operación.
